DÉPÔT DES PREUVES DE PROJETS
============================
Place ici les fichiers référencés dans src/data/content.ts (champ "assets").
Les liens du portfolio pointent vers ces fichiers.

À déposer :
- powerbi-dashboard.pdf       -> captures du dashboard Power BI
- integration-donnees.pdf     -> rapport / livrable du projet d'intégration
- etude-economique.pdf        -> rapport de l'étude économique
- enquete-limesurvey.pdf      -> rapport de l'enquête (BUT1)
- portfolio-v1/               -> ancienne version HTML/CSS (DÉJÀ EN PLACE ✓)

Pour le projet freelance (centre de beauté), mets les vrais liens
(site en ligne + GitHub) directement dans content.ts (champ assets, url: '#').

Tu peux aussi remplacer un asset PDF par une image (type: 'image')
ou un lien externe (type: 'link').
